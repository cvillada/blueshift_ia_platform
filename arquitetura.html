⚠️ Regras de Dependência (Importante)

  • db.py é o ponto único de acesso a dados. Nenhum outro módulo abre SQLite direto.
  • agente.py é o orquestrador central: coordena RAG → conectores → LLM.
  • registry.py (conectores) depende de db.py para listar conectores da área — cuidado com import circular.
  • llm_client.py não depende de nada do projeto — pode ser usado standalone.
  • mcp_erp.py tem dependência opcional de psycopg (Postgres). Se não instalado, cai em fallback de dados de exemplo.
  • templates.py gera HTML inline (sem Jinja2). Todo o CSS/JS está embutido na função page().
  • Conectores por área: agentes herdam os conectores configurados para a área na tela Conectores.
